Machine Learning: A Simple Start for Students

By Omkar Solat | 2 September 2026

Introduction

Machine learning sounds like something only final year students or research scientists do. Actually the basic idea is simple, and you can build your first small model in a single evening.

In this article I will explain what machine learning really means, the three main types, and the steps of a normal project, using one example with plain school maths.

What Is Machine Learning?

In a normal program we write the rules ourselves: if the marks are below 40, print fail. Machine learning is the opposite. We give the computer a set of examples, and it finds the rules on its own.

So a machine learning model is not magic and it is not intelligent like a human. It is a formula that was adjusted until it matched the examples well.

The Three Main Types

  • Supervised learning - we give the computer inputs and the correct answers, and it learns the connection. Example: study hours and attendance as input, marks as the answer. If the answer is a number it is called regression, and if the answer is a group or label it is called classification.
  • Unsupervised learning - we give only the inputs, and the computer finds groups inside the data by itself. Example: grouping customers of a shop by what they buy.
  • Reinforcement learning - the computer learns by trying things and getting a reward or a penalty. Example: a program that learns to play a game.

The Steps Of Any ML Project

  1. Collect the data. Even a small CSV file of 100 rows is a fine start.
  2. Clean the data - remove wrong values and empty cells.
  3. Choose a simple model first. A straight line is a real model too.
  4. Train the model on one part of the data.
  5. Test it on the part you did not use, and measure the average error.
  6. Show the result to the user - a number, a chart or both.

A Tiny Example With Real Numbers

For my project I took twelve rows of student data with three columns: study hours, attendance and marks. I drew the best straight line through those points and got a formula that looks like marks = 16 + 8 x study hours .

With that one line, the average difference between the real marks and the predicted marks was under one mark. Then I put a small form on a web page: the visitor types the study hours, and the page shows the predicted marks.

That is exactly what a big model does. It just uses thousands of columns and millions of rows instead of three columns and twelve rows.

Tools For Beginners

  • Python with the pandas library for handling data.
  • scikit-learn for ready-made models when you want to go one step ahead.
  • Google Colab, which runs Python in the browser for free, with no installation.
  • Chart.js or matplotlib for showing the results nicely.

Where To Start

  1. Be comfortable with Python lists, loops and functions.
  2. Learn the basics of pandas: read a CSV file and look at the columns.
  3. Try the famous iris dataset and see if you can tell the flowers apart.
  4. Learn how to split data into training and testing parts.
  5. Build one small web page that shows the output of your model.

Conclusion

Start small. One CSV file, one simple model and one honest error number teach you more than a month of watching videos. Once you can explain your own tiny model to a friend, the bigger ones stop looking scary.
